Why there is no application server

The forecast is 200 ensemble members over 145 steps, which modern JavaScript runs in a second or two. Keeping it in the browser means the system deploys as static files and runs on a laptop in a control room with no cloud dependency — which is the condition it would actually be used in.

What this architecture does not yet have

No ingestion connector for live telemetry, no persistence, no multi-user state or audit trail. The engine already consumes one noisy stream per facility, so a live feed replaces the generator in Figure 02 and nothing above it changes — but that connector is not built.
